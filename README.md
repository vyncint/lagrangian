# lagrangian

A Lagrangian mechanics engine for Rust: write `L = T - V` in plain generic
Rust and get exact equations of motion by forward-mode automatic
differentiation.

**Status: pre-release.** The repository holds the project setup and the
plan; the crate is being implemented against
[PLAN.md](https://github.com/vyncint/lagrangian/blob/main/PLAN.md) and
[PROMPT.md](https://github.com/vyncint/lagrangian/blob/main/PROMPT.md).
